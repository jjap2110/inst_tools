Herramienta de desarrollo personal, sin vinculación con ningún fabricante. Los valores calculados son de referencia y no sustituyen la calibración del instrumento.
-- RTD (Callendar-Van Dusen, IEC 60751) --
T >= 0: R = R0·(1 + A·T + B·T²)
T < 0: R = R0·(1 + A·T + B·T² + C·(T-100)·T³)
A = 3.9083e-3, B = -5.775e-7, C = -4.183e-12
alpha = 0.00385055 (europeo IEC/DIN)

-- Ni RTD (DIN 43760) --
T >= 0: R = R0·(1 + A·T + B·T²)
A = 5.485e-3, B = 6.65e-6 (Ni)

-- Cu RTD (ASTM/GOST) --
R = R0·(1 + alpha·T), alpha = 4.274e-3

-- Termocuplas (IEC 60584-1, NIST ITS-90) --
Polinomios de referencia V(T) en mV
Ref. juntura fria = 0 °C (o 25 °C seleccionable)
Tipos: J, K, T, E, N, S, R, B
Normas: IEC 60751:2022 (RTD) · IEC 60584-1:2013 (Termocuplas) · DIN 43760 (Ni) · NIST Monograph 175 · ASTM E1137 (RTD) · ASTM E230 (TC).
